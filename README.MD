# Calculadora Web

Este proyecto consiste en una **calculadora básica** con las cuatro operaciones aritméticas principales: suma, resta, multiplicación y división. Está implementada en HTML, CSS y JavaScript, y permite realizar operaciones de forma dinámica en una interfaz web sencilla.

## Funcionalidades

1. **Operaciones Aritméticas**:  
   La calculadora soporta las operaciones básicas:
   - Suma (`+`)
   - Resta (`-`)
   - Multiplicación (`*`)
   - División (`/`)

2. **Interfaz de Usuario**:  
   La aplicación tiene una interfaz gráfica que muestra un campo de texto donde se despliegan las operaciones y los resultados. Además, los usuarios pueden ver las operaciones conforme se ingresan.

3. **Botón de Igual (`=`)**:  
   Después de ingresar los números y la operación, los usuarios pueden presionar el botón `=` para ver el resultado de la operación.

4. **Botón de Borrar (AC)**:  
   Un botón para borrar todos los valores introducidos y limpiar la pantalla.

5. **Botón de Punto Decimal (.)**:  
   Permite ingresar decimales en los números.

## Requisitos

Este proyecto no tiene dependencias externas. Solo es necesario tener un navegador web moderno para ejecutar la aplicación.
